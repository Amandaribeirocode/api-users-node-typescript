# API de Usuários

API REST desenvolvida com Node.js, TypeScript e Express
para gerenciamento de usuários.

## 🚀 Tecnologias

- Node.js
- TypeScript
- Express

## 📚 Conceitos praticados

- API REST
- CRUD
- HTTP Methods
- TypeScript
- Interfaces
- Express
- Controllers
- Services
- Repositories
- Rotas
- Validação de dados
- Organização de projeto

## 📌 Funcionalidades

- Criar usuário
- Listar usuários
- Buscar usuário por ID
- Atualizar usuário
- Atualizar parcialmente usuário
- Deletar usuário

## 🔗 Endpoints

| Método | Endpoint | Descrição |
|---|---|---|
| GET | `/users` | Lista usuários |
| GET | `/users/:id` | Busca usuário |
| POST | `/users` | Cria usuário |
| PUT | `/users/:id` | Atualiza usuário |
| PATCH | `/users/:id` | Atualiza parcialmente |
| DELETE | `/users/:id` | Remove usuário |
